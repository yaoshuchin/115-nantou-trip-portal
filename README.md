## 🛠️ 技術架構
- **前端核心**：純原生 HTML5 + CSS3 + 模組化 JavaScript（無第三方肥大框架依賴，載入秒開）。
- **響應式排版**：CSS Flexbox / Grid，深度適配手機直屏、橫屏、平板與 4K 教室投影機。
